# ROADMAP

La ruta avanza desde representaciones y recuperación hasta herramientas,
agentes, fronteras de confianza y evaluación. Cada fase entrega primero el
contrato y los invariantes, después un modelo probado y finalmente el capítulo
que explica sus límites.

El seguimiento operativo vive en el GitHub Project del curso, creado a partir
del plan versionado.
