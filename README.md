# Rust AI Engineering

Curso de Jeresoft Academy sobre ingeniería de sistemas de IA en Rust:
representaciones, recuperación, herramientas, agentes, seguridad y evaluación
con evidencia reproducible.

La fuente de verdad es el [plan versionado](docs/superpowers/plans/2026-07-29-rust-ai-engineering-course.md).
El contenido inicia en `draft`. Los modelos del crate son locales,
deterministas y didácticos; no sustituyen proveedores, modelos ni revisiones de
seguridad de producción.
