# Glosario

- **Agente:** coordinador que propone pasos bajo un presupuesto y capacidades
  explícitas; no es una autoridad autónoma.
- **Capacidad:** operación permitida por un contrato. Declararla no implica
  ejecutarla.
- **Contexto:** fragmentos seleccionados para una tarea, con presupuesto y
  procedencia.
- **Embedding:** representación numérica usada para comparar objetos bajo una
  métrica; no es una prueba de verdad.
- **Evaluación:** comparación versionada entre una expectativa y una
  observación. Sus métricas tienen límites.
- **MCP:** protocolo para describir integración de herramientas y recursos;
  sigue requiriendo controles de confianza.
- **Procedencia:** identidad y origen de una fuente que permite revisar la
  evidencia.
- **RAG:** recuperación de fuentes y construcción de contexto antes de una
  generación; no garantiza cobertura ni actualidad.
- **Señal de confianza:** indicio explicable que solicita revisión; no prueba
  seguridad ni intención.
